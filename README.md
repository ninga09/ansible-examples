# Ansible Examples

Collection of Ansible playbooks, roles, inventory configurations, and deployment strategies.

## Directory Structure

All learning modules and demonstration projects are organized inside [`ansible-examples-main`](./ansible-examples-main):

- **Part 1 & 4**: First demo and basic playbooks
- **Part 3**: Ansible GCP VM automation
- **Part 6**: Handlers and notification mechanisms
- **Part 7**: Variables, precedence, and facts
- **Part 8**: Environment variables management
- **Part 9**: Conditionals and flow control
- **Part 10**: Roles and task imports
- **Part 11**: Jinja2 templating
- **Part 12**: Deployment strategies (rolling, canary, blue-green)
- **Part 13**: Error handling and rescue blocks
- **Part 14**: Ansible Vault for sensitive secrets
- **EC2 & Remote Automation**: AWS EC2 provisioning & private repository cloning
